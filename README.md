# 🎯 AI面试官助手 — 面向AI岗位的模拟面试智能体

**一句话介绍**：一个专为AI训练师/AI产品助理等岗位设计的AI模拟面试官，帮你随时随地进行高强度的面试演练。

**项目状态**：✅ 已上线，公网可访问


## 🎯 解决了什么问题？

为想要进入AI领域的求职者（比如我自己），解决**缺乏模拟面试机会、不知如何准备、缺乏针对性反馈**的痛点。

## ✨ 核心功能
- **🎯 50道分级题库**：题目覆盖技术、行为与产品思维三大维度，按L1-L3难度分级，精准打击面试官可能问到的各种刁钻问题。
- **🧠 结构化反馈**：AI面试官不仅会提问，还会在每道题回答后，从**准确性、逻辑性、完整性**三个维度给出个性化的改进建议，让你知道哪里不足，如何提高。
- **🕹️ 智能对话状态机**：整个面试过程是精心设计的，包含开场白、方向选择、循环问答、结构化反馈、结束总结等环节，模拟最真实的面试交互逻辑。
- **🔧 复杂工作流编排**：在Dify平台上搭建了复杂的后端工作流，实现了多步骤的复杂任务编排，确保面试流程严谨、高效。
- **🌐 云端部署**：应用已成功部署在阿里云服务器上，实现公网访问，随时随地可用。

## 🛠️ 怎么用？
1. **直接访问**：可以[点击这里](http://8.148.82.198:8088)直接在线使用。
2. **自行部署（可选）**：将 `.yml` 文件导入你自己的 Dify 平台，配置好 DeepSeek 模型 API Key 即可运行。


## 📂 项目里有什么？
| 文件名 | 简介 |
|:--- |:--- |
| `面试题50道.txt` | 50道精心设计的面试题，按技术/行为/产品思维分类，L1-L3难度分级 |
| `AI面试官_ (1).yml` | Agent的核心配置文件，定义了完整的对话规则和Prompt |
| `AI面试官_工作流.yml` | 在Dify上编排的复杂工作流文件，展示了 Agent 的逻辑架构 |


## 🧰 用到了哪些技术？
- **应用平台**：[Dify.ai](https://dify.ai) - 新一代LLM应用开发平台
- **大脑模型**：DeepSeek V3 - 强大的语言模型
- **服务器**：阿里云 ECS - 稳定、高效的云服务器
- **部署**：Docker容器化部署，Nginx反向代理
